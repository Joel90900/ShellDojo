PROGRAMA DE ESTUDIOS DE 42 NIVELES (630 EJERCICIOS)

¿Qué vas a aprender en ShellDojo?

El Plan Gratis (Cadet) incluye 14 niveles completos (210 ejercicios) en 5 áreas prácticas. Los planes de pago suman más niveles y rutas avanzadas.

01 • GIT & GITHUB 3 Niveles • 45 Retos

Git, Ramas & GitHub

Desde `git init`, Staging y commits hasta ramas, fusiones, `stash`, remotos y flujo colaborativo en GitHub.

02 • POWERSHELL 3 Niveles • 45 Retos

PowerShell Moderno

Cmdlets Verbo-Sustantivo: `Get-ChildItem`, `Get-Process`, `Get-Service`, `Test-Connection`, `Copy-Item` y ayuda con `Get-Help`.

03 • GESTORES DE PAQUETES 3 Niveles • 45 Retos

Winget, Chocolatey, PNPM & NVM

Instala y actualiza programas desde la consola (`winget upgrade --all`), gestiona dependencias con `pnpm`, `yarn` y versiones de Node con `nvm`.

04 • COMPRESIÓN & HERRAMIENTAS CLI 3 Niveles • 45 Retos

Tar, Zip, JQ, Sed & Vim

Crea respaldos `tar -czvf`, procesa JSON con `jq`, compara con `diff`, reemplaza texto con `sed` y edita archivos con Nano y Vim.

05 • APIS WEB & DNS 2 Niveles • 30 Retos

cURL, Wget, Dig & Whois

Consume APIs REST (`curl -X POST`), descarga archivos con `wget`, e inspecciona dominios con `dig` y `whois` sin abrir el navegador.

06 • RUTAS AVANZADAS 28 Niveles • 420 Retos

Linux, Docker, SQL, Python & Seguridad

Al activar un plan de pago sumas rutas profesionales de administración Linux, contenedores, bases de datos, backend y ciberseguridad.
